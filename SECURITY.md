# Security Policy

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities. Report privately via the
channel listed in this file once the project publishes contact details (placeholder:
security@0xphone.example — to be replaced before the first release).

## Scope

Custom privileged components (Hermes service, task gateway, permission engine,
Linux-workspace mediation) are the highest-priority review targets.

## Support policy

Security support commitments will be published with the first device image, including
an explicit end-of-support process per device. Until then, nothing in this repo
should be considered production-ready.
