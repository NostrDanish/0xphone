# Governance

- Public governance document and code of conduct (see CODE_OF_CONDUCT.md).
- Documented security vulnerability disclosure process (see SECURITY.md).
- **Two-person review** for security-sensitive changes.
- Protected release branches; separate development and release signing keys.
- Public security support policy and explicit end-of-support process.
- Contributor license policy reviewed by counsel; no unnecessary restrictions on contributors.
- Clear rules for branding and derivative works (see docs/licensing.md).
